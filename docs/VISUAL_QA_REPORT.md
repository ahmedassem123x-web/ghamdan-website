## 4. فحص منع الـ Slop (لكل الصفحات العشر)

| القاعدة | النتيجة |
|---|---|
| بيانات/إحصائيات/شهادات/مشاريع/نتائج مختلقة | **PASS** — لا شيء منها؛ الحالات الفارغة صادقة |
| نص بديل (Lorem ipsum / «نص تجريبي») معروض كحقيقي | **PASS** — لا Lorem؛ كل بديل موسوم «تطويري/مؤقت» |

| زجاجية (glassmorphism) | **PASS** — 0 (`backdrop-filter` غير موجود) |
| أيقونات إيموجي | **PASS** — SVG خطية فقط |
| بنفسجي على أبيض | **PASS** — لا بنفسجي في أي مكان |
| بطل SaaS عام (نمطي) | **PASS** — أبطال فوتوغرافية خاصة بالطاقة/المياه |
| إحصائيات وهمية بعدّاد | **PASS** — العدّاد منفَّذ لكن بلا أي استخدام (لا أرقام) |
| أحمر غمدان خارج الوورد مارك | **PASS** — `#E10600` في `.wordmark__dot` فقط |
| أسعار | **PASS** — 0 حقل سعر في الملفات المعروضة؛ الجملة الوحيدة المسموحة هي جملة السياسة (السعر/التوفر/التسليم يُحدَّدان مع فريق المبيعات عبر واتساب) — انظر TEST_REPORT.md §4 |

**ملاحظتان ليستا Slop لكنهما فجوات:**
- كلمات marquee في `GTS_PAGE_I18N` للصفحة الرئيسية غير مترجمة للصينية
  (القيم الصينية = النص العربي نفسه) — تظهر عربية في وضع ZH.
- 8 مفاتيح من 53 في الرئيسية بلا `zh` (منها نص الحالة الفارغة للمشاريع)
  — يظهر إشعار المراجعة كما هو مصمم (§13.2)، لكنه يبقى نقص ترجمة.
