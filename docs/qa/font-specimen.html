v15 · BRAND & TOKENS · QA SPECIMEN — NOT A SITE CHANGE

عيّنة الخطوط: Plex + Inter مقابل Tajawal + Montserrat

Target (boards): IBM Plex Sans Arabic for Arabic + Inter for Latin — Digital Design System boards 129542 / 129543. Current (live site): Tajawal + Montserrat — public/fonts/, globals.css.

All font files below are vendored locally as WOFF2 (font-display: swap). No font has been swapped on the site — this page is for review only. Sample lines use board-printed taglines and real product data (Deye SUN-SG04LP1-6kW); the Chinese lines are specimen-only sample text, not approved site copy.

Conflict note: the composite board image (129540) prints “Montserrat” as the typeface, while the two standalone Digital Design System boards print “IBM Plex Sans Arabic + Inter”. Per v15 §4 the standalone boards are followed as the target direction.

Chinese coverage — read first: Neither IBM Plex Sans Arabic nor Inter covers CJK. Chinese text on this page renders through the fallback stack ("Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif). The same fallback applies to the current Tajawal + Montserrat stack. A CJK webfont is not vendored — the site should keep relying on system CJK fonts (they are present on the user's devices) rather than shipping a multi-MB CJK file.
