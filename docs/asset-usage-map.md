## 6. Rules that apply to every asset

1. **Zero public prices** — no price in any image, alt text, filename or metadata.
2. **Single WhatsApp** — `wa.me/967775800000` everywhere; no other number in any asset.
3. **LM PACK = Shenzhen Kexin, NOT EFORE** — brand ownership in any caption, filename or alt text must follow this.
4. **No invented content** — no fake projects, customers, locations, capacities or testimonials in any image or caption.
5. **No board crops as production assets** — the boards are references, not asset sources (superseded by the official logo file).
6. **New assets go here** (`public/images/...`, `public/fonts/...`) with a row added to this map — never silently added to a page.
