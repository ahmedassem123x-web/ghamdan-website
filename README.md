## Stack (as built — not the scaffold)
- **Static HTML (75 pages)** generated by `python3 tools/build.py` from `assets/js/data.js`. Repo root = site root.
- **Hand-written CSS** from `docs/DESIGN_SYSTEM.md` tokens (`assets/css/main.css`) — no Tailwind at runtime, no framework.
- **Vanilla JS** (`assets/js/app.js`) + **GSAP 3.12.5 + ScrollTrigger vendored locally** (`assets/js/vendor/`) — no CDN.
- `package.json` (Vite + Tailwind + Lenis) is the **starter scaffold only**; the built site does not use it.
- Laravel/Blade/Filament could not run on this VM (no PHP/Composer) — the static build maps 1:1 to Laravel routes/controllers/Filament resources (see `docs/ARCHITECTURE.md` §5 and `docs/DATABASE_SCHEMA.md`).

## Run it

